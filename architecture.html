Desglose de Componentes (Actualizado)

  • Frontend (React/Vite): La aplicación web de usuario única (SPA). A diferencia de arquitecturas tradicionales, se comunica de forma directa y segura con Supabase para mostrar los datos contables en tiempo real (como el Dashboard y el CRM de Pagos), aligerando enormemente la carga del servidor.
  • Base de Datos (Supabase): Corazón de los datos transaccionales, almacena autenticación de usuarios, permisos, la base de PostgreSQL (con vistas complejas como v_libro_unificado) y almacenamiento de comprobantes (Storage).
  • Backend de Orquestación (Brain API - FastAPI): Un backend moderno ubicado en app/brain, dedicado exclusivamente al trabajo pesado: generación de PDFs masivos, limpieza de datos mediante reglas estructuradas y la orquestación de la IA.
  • Bots de Automatización (Playwright): Scripts de Python gestionados por el Brain API que simulan navegación humana para extraer los registros de compras y ventas de la SUNAT usando las credenciales (Clave SOL) del cliente.
